Experiment 8 - Remote Capture Screen (RCP)

Files:
- ScreenServer.java
- ScreenClient.java
- Experiment-8.docx

Compile:
javac ScreenServer.java
javac ScreenClient.java

Run server first:
java ScreenServer

Then run client:
java ScreenClient

For two computers, replace localhost in ScreenClient.java with the server IP address.
Use screen capture only with permission and knowledge of the user of the remote machine.
