Experiment 9 - Public Key Encryption Using RSA

Files:
1. RSAEncryption.java - Generates an RSA key pair, encrypts plaintext using the public key, and decrypts it using the private key.
2. Experiment-9.docx - Experiment documentation.

Compile:
javac RSAEncryption.java

Run:
java RSAEncryption

Note:
The encrypted Base64 output will differ between runs because RSA encryption uses randomized padding for security.
